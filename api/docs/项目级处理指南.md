# MSST API 项目级处理指南

## 概述

MSST API 完全支持项目级的批量音源分离处理，特别适用于剧集制作、影视后期等业务场景。

## 业务场景

### 典型需求

- **输入**：`/TTD/00_项目/xxx/input` - 剧集文件目录
- **输出**：`/TTD/00_项目/xxx/03_Stem/xxx` - 分离结果目录

### 项目目录结构

```text
/TTD/00_项目/
├── 项目A/
│   ├── input/           # 剧集文件（音频/视频）
│   └── 03_Stem/
│       └── 项目A/       # 分离结果
├── 项目B/
│   ├── input/           # 剧集文件
│   └── 03_Stem/
│       └── 项目B/       # 分离结果
└── 项目C/
    ├── input/           # 剧集文件
    └── 03_Stem/
        └── 项目C/       # 分离结果
```

## 快速开始

### 1. 基本用法

```python
from api.client import MSSTApiClient

client = MSSTApiClient()

# 处理项目目录下的剧集文件
resp = client.create_batch_sync(
    input_path='/TTD/00_项目/demo_project/input',           # 项目输入目录
    output_dir='/TTD/00_项目/demo_project/03_Stem/demo_project',  # 项目输出目录
    model_type='vocal_models',
    model_name='melband_roformer_instvox_duality_v2.ckpt',
    extract_instrumental=['Vocals', 'Instrumental'],
    params={'device_ids': ['cuda:0'], 'use_tta': False},
)

# 获取处理结果
task_id = resp['task_id']
result = client.get_task_result(task_id)
print(f"任务状态: {result['status']}")

# 查看输出文件
for file_result in result['files']:
    input_file = file_result['input_file']
    output_files = file_result['output_files']
    print(f"输入文件: {input_file}")
    for output_file in output_files:
        print(f"  输出: {output_file}")
```

### 2. 流式处理（推荐用于长时间任务）

```python
from api.client import MSSTApiClient

client = MSSTApiClient()

for event in client.create_batch_sse(
    input_path='/TTD/00_项目/demo_project/input',
    output_dir='/TTD/00_项目/demo_project/03_Stem/demo_project',
    model_type='vocal_models',
    model_name='melband_roformer_instvox_duality_v2.ckpt',
    extract_instrumental=['Vocals', 'Instrumental'],
    params={'device_ids': ['cuda:0'], 'use_tta': False},
):
    event_type = event.event
    data = event.data
    
    if event_type == 'start':
        print(f"任务开始: {data['task_id']}")
    elif event_type == 'progress':
        print(f"进度: {data['progress']:.1%} ({data['processed_files']}/{data['total_files']})")
        print(f"当前文件: {data['current_file']}")
    elif event_type == 'completed':
        print(f"任务完成，耗时: {data['duration']}秒")
        print(f"输出文件: {len(data['files'])} 组")
    elif event_type == 'error':
        print(f"任务失败: {data['message']}")
```

## 高级功能

### 1. Range 参数（分批处理）

对于大型项目，可以使用 Range 参数分批处理：

```python
# 处理第1-10个文件
resp = client.create_batch_sync(
    input_path='/TTD/00_项目/demo_project/input',
    output_dir='/TTD/00_项目/demo_project/03_Stem/demo_project',
    range_start=1,
    range_end=10,
    # ... 其他参数
)

# 处理第11-20个文件
resp = client.create_batch_sync(
    input_path='/TTD/00_项目/demo_project/input',
    output_dir='/TTD/00_项目/demo_project/03_Stem/demo_project',
    range_start=11,
    range_end=20,
    # ... 其他参数
)
```

### 2. 文件格式支持

#### 音频格式

- `.wav`, `.mp3`, `.flac`, `.m4a`, `.aac`, `.ogg`

#### 视频格式（自动提取音频）

- `.mp4`, `.avi`, `.mkv`, `.mov`, `.wmv`, `.flv`, `.webm`

#### 自动过滤

- 排除 NAS 系统文件（以 `@` 或 `.` 开头）
- 只处理媒体文件，忽略其他格式

### 3. 模型选择

#### 通用台词人声（推荐）

```python
model_type='vocal_models'
model_name='melband_roformer_instvox_duality_v2.ckpt'
```

#### 加强 ME/伴奏质量

```python
model_type='vocal_models'
model_name='mel_band_roformer_instrumental_becruily.ckpt'
```

## 输出结构

每个任务会在指定的输出目录下创建独立的任务子目录：

```text
/TTD/00_项目/demo_project/03_Stem/demo_project/
└── task_20251121063959815598/    # 任务独立目录
    ├── episode1_Vocals.wav
    ├── episode1_Instrumental.wav
    ├── episode2_Vocals.wav
    ├── episode2_Instrumental.wav
    ├── episode3_Vocals.wav
    └── episode3_Instrumental.wav
```

### 文件命名规则

- 输入文件：`episode1.wav` / `episode1.mp4`
- 输出文件：`episode1_Vocals.wav` 和 `episode1_Instrumental.wav`

## 故障排除

### 常见问题

1. **路径不存在**
   - 确保输入输出目录存在
   - 检查 Docker 挂载配置

2. **权限问题**
   - 确保容器有读写权限
   - 检查目录权限设置

3. **GPU 内存不足**
   - 减少并发任务数量
   - 使用 Range 参数分批处理
   - 考虑使用 CPU 模式

4. **视频文件处理失败**
   - 确保视频包含音频轨道
   - 检查视频格式是否支持
