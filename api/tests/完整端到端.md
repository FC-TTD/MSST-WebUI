# 线上端到端测试

## 测试目标

验证 MSST 批量处理 API 在真实环境中的完整流程，包括：

- API 请求接收与解析
- 输入路径验证
- 任务创建与状态管理
- 模型推理执行
- 输出文件生成与存储
- 任务完成通知
- **Range 参数处理**：支持指定文件范围处理
- **真实文件输出验证**：确保输出文件实际生成且可访问
- **自定义路径支持**：验证独立输入输出目录功能

## 环境

### 客户端环境（开发机）

- 智能体Agent运行在开发机上，通过网络访问线上API服务。
- 开发机可以ssh直连线上服务器,SSH信任已打通。

### 服务器环境（线上）

- MSST API 服务运行在局域网服务器上。
- 模型文件存储在服务器指定目录。
- 任务队列和结果存储在服务器Docker容器的数据库中。
- 可以通过ssh连接服务器后使用docker logs查看日志

### 测试目录与文件

服务器的数据目录与开发机挂载的相同的NAS，测试文件存放在NFS目录中。

映射关系:

- Server:/TTD == Code-Server:/TTD
- Server:/TTD-Data == Code-Server:/TTD-Data

> 测试脚本可以构建在共享存储上的测试数据集进行测试。

## 测试配置

### 环境变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `MSST_E2E_TTD_EDGE_ENABLE` | `0` | 启用线上E2E测试 |
| `MSST_E2E_BASE_URL` | `http://ttd-edge:8662/` | API服务地址 |
| `MSST_E2E_INPUT_PATH` | `/app/input` | 输入文件目录 |
| `MSST_E2E_OUTPUT_DIR` | `/app/results` | 输出文件目录 |
| `MSST_E2E_CONTAINER_MODE` | `1` | 容器模式标志 |
| `MSST_E2E_DEVICE_IDS` | `cuda:0` | CUDA设备格式（注意冒号） |
| `MSST_E2E_MODEL_TYPE` | `vocal_models` | 模型类型 |
| `MSST_E2E_MODEL_NAME` | `melband_roformer_instvox_duality_v2.ckpt` | 模型名称 |

### CUDA 设备格式

**重要**：CUDA设备必须使用 `cuda:0` 格式，而不是 `cuda0`。这是PyTorch的标准设备表示法。

### 项目级处理

API 支持任意项目目录结构，典型业务场景：

- **输入目录**：`/TTD/00_项目/xxx/input` - 剧集文件目录
- **输出目录**：`/TTD/00_项目/xxx/03_Stem/xxx` - 分离结果目录

**使用示例**：

```python
from api.client import MSSTApiClient

client = MSSTApiClient()
resp = client.create_batch_sync(
    input_path='/TTD/00_项目/demo_project/input',
    output_dir='/TTD/00_项目/demo_project/03_Stem/demo_project',
    model_type='vocal_models',
    model_name='melband_roformer_instvox_duality_v2.ckpt',
    extract_instrumental=['Vocals', 'Instrumental'],
    params={'device_ids': ['cuda:0'], 'use_tta': False},
)
```

**输出结构**：

```text
/TTD/00_项目/demo_project/03_Stem/demo_project/
└── task_20251121063959815598/    # 任务独立目录
    ├── episode1_Vocals.wav
    ├── episode1_Instrumental.wav
    ├── episode2_Vocals.wav
    └── episode2_Instrumental.wav
```

### Range 参数功能

- 支持指定文件范围处理：`range_start=1, range_end=3`
- **支持音频和视频文件**：音频格式（`.wav`, `.mp3`, `.flac`, `.m4a`, `.aac`, `.ogg`）和视频格式（`.mp4`, `.avi`, `.mkv`, `.mov`, `.wmv`, `.flv`, `.webm`）
- **视频文件处理**：MSST 通过 librosa + ffmpeg 自动提取视频中的音频进行分离
- **排除NAS系统文件**：过滤以 `@` 或 `.` 开头的文件（如 `.DS_Store`, `@eaDir`）
- 按文件名排序后索引，忽略非媒体文件
- 验证范围有效性，防止越界
- **注意**：视频文件必须包含音频轨道，否则无法处理

### 文件输出验证

- 创建独立时间戳输出目录，避免历史文件干扰
- 验证API返回的文件结果与实际文件系统一致
- 检查每个输入文件生成对应的Vocals和Instrumental输出
- 支持容器模式下的远程验证

## 运行测试

```bash
# 设置环境变量
export MSST_E2E_TTD_EDGE_ENABLE=1
export MSST_E2E_BASE_URL=http://ttd-edge:8662/
export MSST_E2E_INPUT_PATH=/app/input
export MSST_E2E_OUTPUT_DIR=/app/results
export MSST_E2E_CONTAINER_MODE=1
export MSST_E2E_DEVICE_IDS=cuda:0

# 运行所有测试
python3 -m pytest api/tests/test_e2e_ttd_edge_online.py -vv

# 运行特定测试
python3 -m pytest api/tests/test_e2e_ttd_edge_online.py::test_ttd_edge_range_all_files -vv
```

## 故障排查

- 检查容器日志：`ssh ttd-edge "docker logs msst --tail 50"`
- 验证输入文件：`ssh ttd-edge "docker exec msst ls -la /app/input/"`
- 检查输出目录：`ssh ttd-edge "docker exec msst find /app/results -name '*.wav'"`
- 确认CUDA设备：`ssh ttd-edge "docker exec msst python -c 'import torch; print(torch.cuda.is_available())'"`
